# Site Magnolia

"Crie uma landing page de vendas para o '3º Encontro das Magnólias'. Use um design botânico premium com tons de rosa queimado (dusty rose) e off-white. Inclua um banner com flores de magnólia, o título elegante, e as informações: Data 22 de Maio, 15:30h, em Goiânia. Adicione o versículo de Salmos 1:3: 'Pois será como a árvore plantada junto a ribeiros de águas...'. O estilo deve ser sofisticado e acolhedor."
